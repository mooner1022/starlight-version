### 주요 변경 사항
+ **메신저봇 호환 API** 완성
  + 레거시·API2 스크립트가 메신저봇R과 같이 동작하도록 `Api`, `Utils`, `DataBase`, `Bridge`, `App`, `BotManager`, `Broadcast`, `Device`, `FileStream` 보강
  + `AppData`, `GlobalLog`, `Http`, `Security`와 API2의 `Database` 추가
  + `SessionManager`와 레거시 `onNotificationRemoved` 추가, `response`가 11개 인자를 모두 전달
  + Rhino 프로젝트에도 `console` 추가
  + 여러 알림 규칙(다른 메신저, 듀얼 메신저)의 방도 보관해, 방 이름이나 ID로 답장 가능
+ **새 스크립트 API** (StarLight 오리지널)
  + `Store`: 컴파일과 앱 재시작 후에도 유지되는 값 저장소
  + `Chat`: `Chat.waitFor`로 다음 메세지를 답으로 기다리고, `Chat.findRoom`·`Chat.getRooms`로 보낼 방 찾기
  + `Schedule`: 매일, cron, 한 번 실행하는 작업과 앱을 재시작해도 남는 `Schedule.at` 작업
  + `Format`: 숫자, 날짜, 시간 길이, 한국어 조사(`을/를` 등)를 문자열로 만들기
  + `onUncaughtError`: 처리되지 않은 오류를 받는 이벤트 리스너
+ **카카오톡 공유로 텍스트 보내기**: `MediaSharer.sendText`, '나와의 채팅'으로 보내는 `MediaSharer.sendTextToMemo`
  + 스포일러와 미니 이모티콘(카카오톡 계정이 가진 것만) 사용 가능
  + 마크다운은 보낸 기기에서만 서식이 적용되고, 방의 다른 사람에게는 서식 없는 텍스트로 표시
+ **에디터 코드 검사** 개선
  + NeonJS·Rhino 프로젝트를 neonjs-lint로 검사, 여러 문제를 한 번에 한국어로 표시
  + `#private` 멤버, `3600_000` 같은 최신 문법을 오류로 표시하던 문제 수정
+ **알림 팝업** 개편: 모든 알림을 같은 모양으로 통일하고, 연달아 뜬 알림을 덮어쓰지 않고 쌓아서 표시

### 버그 수정 / 개선 사항
+ 다시 컴파일하다 실패한 프로젝트가 실행 중으로 보이던 문제 수정, 첫 컴파일이 실패하면 타이머도 정리
+ 화면 회전이나 테마 변경 시 설정, 프로젝트 설정, 새 프로젝트 마법사, 디버깅 룸, 에디터에서 저장하지 않은 내용이 사라지던 문제 수정
+ 에디터가 다른 곳(StarLight AI 등)에서 바뀐 파일을 알아채고 다시 불러오거나 확인
+ 스크립트 오류를 파일·줄·열과 함께 한 번만 기록하고, 에디터에 실행 중 오류도 표시
+ 어느 프로젝트에도 전달되지 않은 메세지 알림을 원인별로 문제 해결 도우미에 표시
+ 로그 필터가 태그나 내용의 일부로도 검색
+ 시작할 때 아직 표시 중인 카카오톡 알림의 방을 복원해, 새 메세지가 오기 전에도 답장 가능
+ 코드가 오래 실행되면 로그에 경고 (프로젝트 설정의 '느린 실행 경고 (초)', 기본 10초)
+ StarLight AI: 파일을 덮어쓰기 전 확인, 되돌리기 취소, 켜진 프로젝트를 컴파일하기 전 확인, 별도의 중지 버튼, 단계 한도에 걸리면 알림
+ 채팅 로그 ID가 없는 메신저에서 첫 메세지 이후의 메세지가 무시되던 문제 수정
+ 가져온 프로젝트가 바로 실행되지 않고 꺼진 상태로 추가
+ StarLight가 방을 읽음 처리하거나 공유로 방을 연 뒤 `onMessageDeleted`가 잘못 호출되던 문제 수정
+ 플러그인 하나가 실패해도 다른 프로젝트와 플러그인이 영향을 받지 않도록 개선, 업데이트한 플러그인의 네이티브 라이브러리를 새로 적용
+ 반복된 충돌로 시작이 막힌 뒤 앱을 열면 무한 로딩 대신 충돌 보고를 표시
+ `Api.isCompiling`이 항상 `false`를 반환하던 문제 수정
+ 태블릿 모드의 디버깅 룸에서 로그 알림이 두 번 뜨던 문제, 바텀 시트를 닫을 때 앱이 종료될 수 있던 문제 수정

### 호환성 / 주의 사항
+ 미디어 전송의 '전송 후' 기본값이 '홈 화면으로 이동'으로 바뀌었습니다. '카카오톡에 머물기'를 직접 선택했다면 그대로 유지됩니다.
+ 메신저봇R과 같아지도록 일부 레거시 API의 동작이 바뀌었습니다.
  + `Utils.getWebText`가 태그를 제거한 텍스트 대신 HTML을 반환
  + `getPhoneBrand`가 제품명 대신 브랜드를, `getPlugType`이 AC 충전기에서 `"ac"`를 반환
  + `getBatteryTemperature`가 섭씨 온도의 10배(31.5 °C는 `315`)를 반환, `isCharging`이 무선 충전도 충전 중으로 판단
  + `toast`의 기본 표시 시간이 짧게 바뀜
  + `Replier.reply(room, …)`가 알 수 없는 방이면 자기 방으로 보내지 않고 `false`를 반환
  + `Log.d(data, true)`처럼 두 번째 인자가 `Boolean`이면 토스트 표시 여부로 처리
  + `Event.BATTERY_LEVEL_CHANGED` 제거
+ Rhino 스크립트의 최상위 `const`가 같은 이름의 API보다 우선합니다. (예: `const Chat = …`)
+ 진동(`Utils.vibrate`)과 Wi-Fi 정보 권한이 추가되었습니다. 별도의 승인은 필요하지 않습니다.
+ 업데이트 후 처음 시작할 때 모든 플러그인의 파일을 한 번 다시 풉니다.
