### 주요 변경 사항
+ **API 방식** 선택 추가
  + 프로젝트마다 StarLight 오리지널, 메신저봇 API2, 메신저봇 레거시 중 쓸 방식을 골라, 고른 방식의 객체와 이벤트만 받음
  + 새 프로젝트 만들기와 프로젝트 설정에서 선택, 새 StarLight 오리지널·API2 프로젝트는 NeonJS로 시작
  + 앱 전체 설정이던 '레거시 이벤트 사용'은 레거시 방식으로 대체
+ **메신저봇 API2** 개선
  + kbotdocs에 문서화된 API2 동작에 맞춤 (`BotManager`, `Bot`, `Event`, `msg`, `cmd` 등)
  + `bot.on`/`addListener`로 받는 API2 이벤트(메시지, 명령어, 알림 게시·삭제, 컴파일 시작) 추가, 프로젝트의 켜기·끄기와 받을 이벤트 설정을 따름
  + 새 API2 프로젝트는 kbotdocs의 예제 코드로 시작
+ **받을 이벤트** 선택 개편
  + 이벤트 ID를 직접 입력하는 대신, StarLight·플러그인별로 묶인 이벤트 목록에서 체크해 선택
  + 이벤트마다 언제 발생하고 스크립트가 어떻게 받는지 표시, 나중에 추가되는 이벤트도 받을지 선택
  + 저장하면 다시 컴파일하지 않아도 바로 적용
+ **디버그 룸** 개편
  + 카카오톡과 같은 글자 크기, 읽기 쉬운 말풍선 색, 보낸 시간과 날짜 구분선
  + 같은 사람이 같은 분에 보낸 메시지를 묶어 표시, 바로 오는 답장도 늦지 않게 표시
  + 상단 설정 버튼, 빈 대화방 안내, 긴 메시지를 길게 눌러 전체 복사
+ **색 선택 창** 개편
  + 앱의 시트 디자인으로 바꾸고, 팔레트와 직접 고르기(색상환, 밝기, 불투명도, 색 코드) 지원
+ **오류 복구** 개선
  + 한 번 난 오류로는 앱 시작을 막지 않고 알림으로 알림, 같은 오류가 반복될 때만 시작을 막음
  + 시작이 막혔을 때 플러그인과 프로젝트 컴파일을 건너뛰는 안전 모드로 한 번 시작 가능

### 버그 수정 / 개선 사항
+ NeonJS 프로젝트를 다시 컴파일할 때 이전 실행 환경이 해제되지 않아 메모리가 쌓이던 문제 수정
+ 스크립트 최상단에서 등록한 API2 리스너(`bot.on`, `Broadcast.register`)가 컴파일 직후 사라지던 문제 수정
+ 앱이 종료될 때 켜져 있던 프로젝트가 다음 시작에서 꺼져 있던 문제 수정
+ Rhino 프로젝트의 리스너가 자바스크립트 값 대신 자바 값을 받아 문자열 비교가 실패하던 문제 수정
+ 오류로 앱이 다시 시작된 뒤 홈 화면이 비어 보이던 문제 수정
+ 색 선택 창을 다시 열면 직전에 고른 색이 아닌 처음 색이 선택되어 있던 문제 수정
+ 레거시 `response`의 일곱 번째 인자 `packageName`이 전달되지 않던 문제 수정
+ StarLight AI가 참고하는 앱 문서를 1.0.1에 맞게 갱신

### 호환성 / 주의 사항
+ 기존 프로젝트는 세 API 방식을 모두 받도록 설정됩니다. '레거시 이벤트 사용'을 꺼 두었다면 `response`는 계속 받지 않습니다.

### 개발자 변경 사항
+ PluginCore 1.0.1
+ `ProjectEvent.dispatch`, `generateCode`, `description`, `usage`와 `Project.runEvent` 추가: 이벤트가 스크립트에 전달되는 방식과 시작 코드를 이벤트가 정함
+ `ApiLevel`과 `Session.apiLevelManager`, `ProjectInfo.apiLevels`, `Language.nativeGlobals` 추가
+ 받을 이벤트 항목에서 `!`로 시작하는 제외 항목 지원 (`starlight.*`와 `!starlight.message.legacy` 등)
+ 프로젝트 생명주기 관찰자가 상태를 바꾸는 스레드에서 바로 호출되고, `onCompileEnd`도 호출됨
+ ConfigDSL: 호스트가 색 선택 창을 띄우는 `ConfigDialogProvider.color` 추가, 여러 선택 항목의 요약을 한 줄에 하나씩 표시
